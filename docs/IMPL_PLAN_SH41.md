## 3. 画面の中身

**SF History と同じ道具立てを、キューブ4種に対して出す**(ユーザー指示「同様の情報を全部」)。

- **装備の選択**(検索。SF と同じ挙動・同じ代表/alias)
- **キューブ4種の選択**(どれを見るか)
- **価格の推移チャート**(**期待値ではなく生の価格**。K1)
- **期間タブ**(7 / 14 / 30 / 90 / 150日。SF と同じ)
- **現在値 / 期間平均 / 期間高値 / 期間安値**
- **現在の位置**(パーセンタイル。「この期間の◯%より安い」)
- **曜日 × 時間帯**(中央値。**UTC 基準・木曜起点・現在セルの枠**。SH-35/37 の性質を維持)
- **未終了足の破線**(SH-19 の規則)

### 3-1 ★流用すること(作り直さない)

`domain/series.js` / `weekdayStats.js` / `format.js` の**統計・整形の道具は SF 側と共有**する。
**同じ計算を別実装で持たない**(乖離の温床になる)。

**共有できない場合は停止して報告**すること。「似て非なる2つ目」を勝手に作らない。

### 3-2 ★White の欠損を隠さない

**2026-06-11 より前は `null`**。**0 として描かない。前の値で埋めない。**
線が途中から始まるのが正しい。**必要なら「White は 2026-06-11 から」と事実を注記**してよい
(**評価語は書かない**)。

### 3-3 4種の同時表示か、1種ずつか

**実装担当の裁量**。ただし:
- **4種を1つのチャートに重ねる場合**、価格帯が違う(実測: 63万〜120万)ので**読めること**を確認する
- **1種ずつ切り替える場合**、**どれを見ているか常に分かる**こと
- **どちらを選んだか、理由とともに報告する**
