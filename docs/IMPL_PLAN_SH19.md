# IMPL_PLAN_SH19 — 破線は「進行中の足」1点だけにする

前提: SH-18 完了・統括検収済(`5f9fc4f`)。**ユーザー指摘 2026-08-05**。

## 0. 背景 — 統括の読み違いの是正

ユーザーの元指示(SH-17 時):
> 破線は**2種**表示せず、未終了の足については「現在時刻」を表示

**統括はこれを「2*種類*にしない」と解釈**し、「完成済み未保存の足」と「進行中の足」は
どちらも*足*だから1種類、と結論した(SH-17 §1)。

**正しい意図は「破線を2*つ*表示しない」= 最後の1点だけ破線**だった。
ユーザーが実機で2点の破線を見て再指摘した。**統括の読み違いであり、実装担当の誤りではない。**

### 0-1 いま2つになる理由

```
04:00–08:00 の足 → 終了済み。ただし 4h テーブルに未保存 → 破線(SH-13 の規約)
08:00–12:00 の足 → 進行中                              → 破線
```

SH-13 で決めた規約が原因:
> **4h テーブルに在る = 確定(実線)/ 在らず hourly から導出 = 暫定(破線)**

**ローカルは timer が無いので常時この状態。本番でも足の境界から次のジョブ(:43)まで
最大43分間**同じ状態になる。

### 0-2 「最後の表記が変わった」について(変わっていない)

進行中の足のヘッドラインが `07:20` → `08:00` になったのは、
**上流スタンプが 07:40 → 08:00 に進んだ**ため。**ルール(進行中の足は現在時刻)は不変**で、
たまたま現在時刻が足の境界と一致しただけ。**本スライスでこの挙動は変えない。**

## 1. 変更後の規約

**線種の判定基準を「保存されているか」から「足が終わったか」に変える。**

| 足の状態 | 4h テーブル | 線 | 統計 |
|---|---|---|---|
| 終了済み・保存済み | 在り | **実線** | **入る** |
| **終了済み・未保存**(hourly から導出) | 無し | **★実線**(変更) | **入らない**(変更なし) |
| 進行中 | 無し | **破線** | 入らない |

∴ **破線は常に「進行中の足」1点だけ**になる。

### 1-1 ★線種と統計の基準が分かれることを明示する

- **線種** = 足が終わったか(ユーザーに見える性質)
- **統計** = 4h テーブルに保存されているか(再現性のための性質)

**この2つを分ける理由**: 統計に未保存の足を入れると、
**次のジョブで値が変わったときに平均・パーセンタイルが動き、再現しなくなる**
(設計 §6.1 で現在値を統計に入れない理由と同じ)。
**1点の差は900点の中央値・平均にほぼ影響しないが、再現性は原則として守る。**

**この分岐を `sfhistory.css` かコンポーネントのコメントに明記すること**(後任が「なぜ実線なのに
統計に入らないのか」で迷わないように)。

### 1-2 トレードオフ(記録する)

終了済みだが hourly が埋まりきっていない足が**実線**になる。
その値は次のジョブで**微修正されうる**。
本番では8時間の重複窓で速やかに埋まるため実害は小さい、と判断する。
