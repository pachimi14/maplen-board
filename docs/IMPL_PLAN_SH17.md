# IMPL_PLAN_SH17 — ツールチップに足の範囲を出す / 破線を1種類に戻す

前提: SH-16 完了・統括検収済(`56c2236`)。**ユーザー裁定 2026-08-05**。

## 0. 背景と裁定

ユーザー指摘:
> 現在時刻 6:20 で 4:00 が破線になるのはなぜ?

統括の回答: ラベル `04:00` は「04:00 時点」ではなく **「04:00〜08:00 の4時間足」**の意味で、
現在 07:11 なのでこの足はまだ終わっていない(設計 §8 でラベルを**区間開始**に統一しているため)。

**ユーザー裁定**(選択肢 (a) を採用 + 追加指示):
1. **ツールチップに足の範囲を出す** — 例 `04:00–08:00 の足(未終了)`
2. **破線を2種類にしない**。**未終了の足については「現在時刻」を表示する**

∴ **SH-16 で分離した「現在値の独立点」を廃止し、未終了の足に統合する。**

> **SH-16 との関係**: SH-16 は「位置と時刻の食い違い」を、**現在値を自分の時刻に置く**ことで解いた。
> 本スライスは同じ問題を、**範囲の注記で位置の意味を説明する**ことで解く。
> **ユーザーが後者を選んだ**ので前者を戻す。**SH-16 のサーバー側変更(`current` 点)は撤回**するが、
> **SH-16 が直した「足の点に時刻が出ない」問題は維持する**(これは戻さない)。

## 1. 変更後のモデル

| 点の種別 | x 位置 | ツールチップの時刻 | 範囲の注記 | 線 | 統計 |
|---|---|---|---|---|---|
| **確定した足** | 足の開始 | **足の時刻**(従来どおり) | `HH:MM–HH:MM の足` | 実線 | 入る |
| **暫定の足**(完成済み未保存) | 足の開始 | **足の時刻** | `HH:MM–HH:MM の足` | 破線 | 入らない |
| **未終了の足**(進行中) | 足の開始 | **★現在時刻(`asOf`)** | `HH:MM–HH:MM の足(未終了)` | 破線 | 入らない |
| ~~現在値の独立点~~ | — | — | — | **★廃止** | — |

**破線は「足」の1種類だけ**になる(完成済み未保存 / 未終了 のどちらも足)。

## 3. サーバー側

- **`current: true` の独立点を出すのをやめる**(SH-16 のこの部分を撤回)
- **未終了の足の点に `asOf` を付ける**(値は `latest` 由来。SH-13/SH-15 と同じ)
- **`date` は足の開始時刻に戻す**(位置は足の枠)
- **完成済み未保存の足**は従来どおり hourly 由来・`asOf` なし
- `provisionalDate` は**最も新しい暫定点**(= 未終了の足)を指す
- **上流失敗時**: 未終了の足を出さない(または hourly から出す)。**`prices` は 200 のまま**
- **4h テーブルには書かない**

## 4. フロント側

### 4-1 時刻の出し方

- **`asOf` がある点**(= 未終了の足)→ **`asOf`(現在時刻)を表示**
- **`asOf` が無い点** → **`date`(足の時刻)を表示**
- **どの点でも時刻が出ること**(SH-16 で直した性質を壊さない)

### 4-2 範囲の注記

既存の `sfhistory.chart.tooltipBucketNote`(「4時間足(区間終値)」)を**範囲表示に置き換える**:

- 確定・完成済み: `00:00–04:00 の足`
- 未終了: `04:00–08:00 の足(未終了)`

- **範囲は UTC**(SH-14)。日付をまたぐ場合(`20:00–00:00`)も**正しく出す**
- **6ロケール同時**にキー追加/更新

## 5. 受け入れ基準

- **(a)** `/prices` の応答に **`current: true` の点が存在しない**
- **(b)** 未終了の足の点に **`asOf` が付く**。`date` は**足の開始時刻**
- **(c) ★破線が1種類**: 暫定点はすべて「足」。**中抜きマーカーの数 = 暫定の足の数**
- **(d) ★時刻が全点で出る**(SH-16 の性質維持)。時刻が空の点が**ゼロ**
- **(e)** ツールチップに範囲が出る。**未終了には「(未終了)」が付く**。
  **日付をまたぐ `20:00–00:00` が正しく出る**ことをテストで固定
- **(f) 統計不変**: 確定点のみのときと平均・高値・安値・現在の位置・ヒートマップが
  **1ビットも変わらない**。暫定点を改竄しても不変
- **(g) 4h テーブル不変**: 行数・ハッシュがサービング前後で一致
- **(h)** 上流失敗時に `prices` が **200** で返る
- **(i)** `pytest` 全緑(オフライン)/ `npm run test` 全緑 / `npm run build` 成功
- **(j)** 6ロケールのキー数一致
- **(k)** SH-7〜SH-16 の性質維持(UTC・意味色・2桁表記・プリセット3種・
  パーセンタイル文言・20分スタンプ・maxStar ガード・alias 検索・ナビ・テーマ・ヒートマップ起点)
