## 1. 現状(SH-41)

`CubeTypeSelector` で**1種だけ**選び、`SfHistoryChart` を**単系列のまま**再利用している。
∴ **多系列化が本スライスの実体**。

## 2. 実装

### 2-1 選択

- **メインの選択は現状のまま**(`CubeTypeSelector`)
- **追加の選択を別に設ける**(メインとは別の操作)。**メインを追加でも選べる、という重複を作らない**
- **追加ゼロ(メインだけ)が初期状態**。**いきなり4本出さない**
- **メインを切り替えたとき、追加の選択がどうなるかを決めて報告する**
  (引き継ぐ / 解除する のどちらでもよいが、**驚きが少ないほうを選び、理由を書く**)

### 2-2 描画

- **メインが最も太い**。追加は**細い**
- **色は種別ごとに固定**(**テーマ非追従**)。既存の `--sfh-color-cheaper`(#3b82f6)/
  `--sfh-color-costlier`(#fb7185)と**同じ流儀**
  - **★この2色をキューブ線に流用しない**。あちらは「安い/高い」という**意味を持つ色**で、
    線に使うと**その線が安い/高いを表している**と誤読される
  - **4色が互いに判別でき、4テーマ × 3段階すべてで見える**こと。**実測して報告**
- **★凡例が必須**(色が意味を持つため)。**どの色がどのキューブか**が分かること
- **破線(未終了足)の規則を維持**(SH-19)。**4本それぞれで未終了足が破線**になること
- **網掛け・現在セルの枠など既存の描画規則を壊さない**

### 2-3 縦軸

実測でキューブの価格帯は **63万〜120万**(2倍弱)。**同一軸で読める**。

- **軸を分けない**(2軸にすると比較が誤読の温床になる)
- **将来価格帯が大きく開いた場合に破綻しないか**を確認し、**所見を報告**する
  (対応は本スライスでは不要)

### 2-4 White の欠損

**2026-06-11 より前は `null`**(SH-41 (e))。
**重ね描きでも 0 や前値で埋めない。**線が途中から始まるのが正しい。

## 3. 曜日 × 時間帯

**メインのキューブのみ**を集計して表示する(ユーザー指示)。

- **追加で選んだキューブはヒートマップに影響しない**
- **どのキューブのヒートマップか、画面から分かる**こと
- **集計規則は不変**(UTC 基準・木曜起点・現在セルの枠)

## 4. 統計カード(現在値 / 平均 / 高値 / 安値 / パーセンタイル)

- **メインのキューブのもの**を出す(ヒートマップと揃える)
- **追加のキューブの統計は出さない**(**画面が主張を増やしすぎない**)。
  **ただし判断が必要と感じたら、選択肢を添えて停止・報告してよい**
