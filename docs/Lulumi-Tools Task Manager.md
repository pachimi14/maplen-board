# Lulumi-Tools Task Manager 要件・ゴール

## 目的

Lulumi-Tools内に、MapleStory Nプレイヤー向けのタスク管理ページを追加する。

このページは単なるチェックリストではなく、

> **「MapleStory Nをプレイするとき、とりあえず開いておくページ」**

を目指す。

将来的にはDashboardの中心機能となり、EXP Ranking・Gear Simulator・リアルタイム情報などと統合されることを想定する。

---

# MVPで実現したいこと

## 1. タスク管理

以下の4種類を管理できるようにする。

* Daily
* Weekly
* Monthly（実装優先度は低め）
* Event

### Daily

* Dailyリセットまでの残り時間を表示
* 運営プリセットを提供
* ユーザー独自タスクも追加可能
* 完了チェック
* 通知対象設定

### Weekly

* Weeklyリセットまでの残り時間を表示
* 運営プリセット
* ユーザー独自タスク
* 完了チェック
* 通知対象設定

### Event

イベントごとに期間を持つ。

例

* イベント開催期間
* 報酬受取期間
* ショップ交換期間

イベント内では

* Daily
* Weekly
* 期間中1回

など様々なタスクを管理できるようにする。

---

# 運営プリセット

運営側で

* Daily
* Weekly
* Event

のプリセットを配布できるようにする。

ユーザーは

* 有効化
* 非表示
* 並び替え
* 通知対象
* キャラクター割り当て

など、自分用にカスタマイズできる。

また、ユーザー自身が独自タスクも追加できる。

---

# 保存

最初はブラウザのみで完結させる。

ログイン不要で利用できることを目標とする。

ブラウザデータは永続化されること。

バックアップ・復元もできるようにしたい。

---

# Discord通知（将来実装）

将来的にDiscordと連携し、

未完了タスクをDMで通知する。

仕様

* Discordアカウント連携
* DM通知
* 通知時刻は1時間単位
* 1日最大1回
* 未完了タスクのみ通知

通知対象は

* Daily
* Weekly
* Event

から選択できる。

---

# Dashboardとの統合

Task Managerは単独ページとして完結するが、

将来的にはDashboardの一部として利用する。

Dashboardでは

* 今日のタスク進捗
* Daily進捗
* Weekly進捗
* Event進捗
* リセットまでの時間
* イベント終了まで

などを表示する。

---

# 将来的なEXP連携

将来的にはNavigatorと連携し、

* 現在のEXP
* 今日の獲得EXP

などもDashboardへ表示したい。

ただしこれはMVP対象外。

---

# UIコンセプト

目標は

> **「MapleStory Nを起動したら、とりあえず開いておくページ」**

である。

そのため

* 情報量が多くても見やすい
* 一目で今日やることが分かる
* 今日終わっていないタスクがすぐ分かる
* リセットまでの時間が分かる
* イベント終了までの期限が分かる

ことを重視する。
