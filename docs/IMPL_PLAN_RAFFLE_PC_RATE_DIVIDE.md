# IMPL_PLAN — Power Crystal レートを「1 NESO = X PC」(除算方式)へ変更

> 状態: 統括承認済み(ユーザー詳細指示 2026-08-13 = LULU-099)
> ブランチ: `codex/raffle-calculator`(コミットする・push しない)

## 1. 確定仕様

- 入力の意味を変更: 旧「1 Power Crystal = [X] NESO」(乗算)→ **新「1 NESO = [X] Power Crystal」(除算)**。ゲーム内・ユーザー間の「パワクリ1.1倍」をそのまま入力できるようにする
- **換算式: PC の NESO 換算額 = PC 数 ÷ レート**(メンバーごとに計算)
- **丸め: 四捨五入**(ユーザー例示に一致: 100,000,000÷1.1=90,909,090.909…→90,909,091 / ÷1.2→83,333,333 / ÷1.3→76,923,077)。実装は BigInt の厳密有理数で `round(amount × denominator / numerator)`(round half up)。**浮動小数点禁止**。旧 `fractional_neso` エラー(PC経路)は廃止(除算では割り切れないのが常態のため)
- **レートの妥当域: > 0**。`0` と空欄と不正値は `invalid_rate`(÷0 防止。「PCを含めない」は既存のチェックボックスで行う)。上限は既存 MAX_INPUT_DIGITS を踏襲
- **デフォルト値: `1.1`**(旧 `1`)
- UI:
  - ラベル: 「Power Crystal換算レート」→「**Power Crystal レート**」(既存キー `raffle.powerCrystalRate` の文言修正)
  - インライン形式: `1 NESO = [1.1] Power Crystal`(既存 prefix/suffix キーの文言修正)
  - 直下に補足(新キー): 「**Power CrystalをNESO換算する際は、設定したレートで割って計算します。**」
- 6ロケール同時修正・追加

## 3. 受け入れ基準(数値)

1. **レート1.1 で 100,000,000 PC → 90,909,091 NESO**(テストで固定)。同様に 1.2→83,333,333 / 1.3→76,923,077 / 1.0→100,000,000
2. 上記が合計価値・分配権利・支払受取・繰越・「うちPC換算」・共有画像モデルまで**同一値で一貫**(二重変換なし。経路ごとの期待値をテストで固定)
3. rate=0・空欄・負値・不正文字列 → `invalid_rate`(計算せず)
4. 既定値 1.1 が新規パーティ・リセット時に適用される
5. 旧表記(乗算形式)の文言が6ロケール全てから消えている(grep 0件)
