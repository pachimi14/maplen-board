## 1. A — 減光を廃止する

**`n` の多寡でセルの見た目を変えない。**150日のときと同じ濃さで常に描く。

- **`LOW_N_THRESHOLD` / `isLowN` / `.sfh-heatmap-cell-weak` を削除**する
  (**未使用の CSS を残さない**)
- **★色分け(中央値による濃淡)は残す。**廃止するのは**標本数による減光だけ**。
  この2つを混同しないこと(`ratio` / `color-mix` の式は無改変)

### 1-1 標本数の注記は残す

SH-29 §4-1 の**1行の注記**(選択中の期間の1セルあたり標本数)は**そのまま残す**。
**「中央値」という語が嘘にならないための情報**であり、減光とは別の手段。
**ユーザーが消せと言ったのは減光であって、注記ではない。**

## 2. B — 現在時刻のセルを示す

### 2-1 どのセルか

行 = **UTC の曜日**、列 = **UTC の4時間バケット**(SH-14/SH-18 の規則)。
∴ 現在のセルは **`(現在UTCの曜日, floor(現在UTC時 / 4))`**。

- **★セルの割り当て規則を1ビットも変えない**(SH-29 (c) の性質)。
  **どのセルを指すかを計算するだけ**で、集計には触らない
- **データが無いセル(進行中の足など)でも印を付ける**。
  「いまはここ」はデータの有無と無関係

### 2-2 見せ方

- **枠線(リング)で示す。背景色は変えない** — 背景は中央値の色分けに使われており、
  そこを奪うと**価格の高低が読めなくなる**
- **最安・最高のバッジと同時に成立する**こと(重なっても両方読める)
- **色は既存のテーマ変数を使う**(固定色を新規に足さない)
- **凡例か注記で「これが現在」と分かる**ようにする。**枠だけで意味が伝わる前提にしない**
- スクリーンリーダー向けに、そのセルが現在であることを**テキストでも示す**
  (`aria-label` / `title` のいずれか)

### 2-3 更新について(★割り切り)

**描画時に計算するだけでよい。タイマーで自動更新しなくてよい。**
∴ **タブを長時間開いたままだと印が古くなる**。これは許容する。
**この割り切りを報告に明記すること。**隠して「常に正確」と書かない。
