## 0. 現状の問題

```
[キューブ種類]  Red Cube / Black Cube / ...        ← メイン選択
[比較するキューブ] Black Cube / Bonus / White       ← ★ここで選ぶ
[期間] 7日 14日 30日 90日 150日
下の統計とヒートマップは RED CUBE のみが対象です。
[現在値][期間平均][期間高値][期間安値][現在の位置]
● Red Cube (メイン)                                 ← ★ここに結果が出る
[チャート]
```

**選ぶ場所と、結果が現れる場所が離れている。**間に期間タブと統計カード5枚が挟まっている。

## 1. 変更内容

**凡例の行を、そのまま選択の操作にする。**

```
● Red Cube (メイン)  ● Black Cube  ● Bonus Potential Cube  ● White Cube
   ^^^^^^^^^^^^^^^   ← 選択中は枠付き。クリックで切り替え
```

- **「比較するキューブ」の独立したコントロールを廃止**し、**凡例の行に統合**する
- **メインは凡例の左端**。**メインは枠の対象外**(常に表示されるため。**クリックで消せない**)
- **追加3種は凡例の右側に並べ、クリックで表示/非表示を切り替える**
- **★選択中は枠を付ける**(ユーザー指示)。**未選択との違いが一目で分かる**こと
- **色の点(スウォッチ)は選択に関わらず出す**。**どの色がどのキューブかは常に分かる**こと
- **チャートの直前に置く**(操作と結果を隣接させるのが本件の目的)

### 1-1 ★メインの選択(`キューブ種類`)は動かさない

ユーザーが移動を指示したのは**比較するキューブ**のみ。**メインのセレクタは現在の位置のまま**。
